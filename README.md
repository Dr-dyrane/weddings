# Weddings by Dyrane

A reusable platform for wedding invitations that behave like explorable digital worlds rather than static event pages.

The canonical experience follows Alexander and Chioma through a scroll-directed 3D journey: a tactile envelope opens, an acrylic invitation emerges, the camera travels through relationship milestones, the venue reveals the wedding details, and the world resolves into a progressively disclosed RSVP experience.

## Product direction

- Public and personalized invitation links
- Dynamic social preview cards per wedding and guest
- Theme-driven 3D wedding worlds
- Progressive AI-assisted couple onboarding
- Guest lists, event access, plus-ones, meals and RSVP workflows
- Real-time couple notifications and social sharing
- Graceful reduced-motion and low-power experiences

## Development

```bash
npm install
npm run dev
```

Production validation:

```bash
npm run lint
npm run build
```

The current wedding is simulated. Dates, locations, story milestones and RSVP delivery are representative product data.
