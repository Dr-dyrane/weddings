# Dyrane Weddings

A reusable invitation product in which a formal share card opens into a cinematic, accessible wedding story.

Alexander and Chioma are the yardstick build. The current content is simulated and exists to prove the publishing, invitation, people, vendor, calendar, metadata, and presentation boundaries before real couple data is connected.

## Current routes

- `/the_ogranyas` — generic public invitation
- `/the_ogranyas/invite/{opaqueToken}` — personalized, non-indexable invitation
- `.../calendar` — downloadable calendar for the published events
- Dynamic 1200×630 generic and personalized share cards are generated by Next.js metadata routes.

The checked-in personalized token is a non-secret preview fixture. Production credentials will be random, hashed at rest, revocable, and supplied by the invitation service.

## Development

```bash
npm install
npm run dev
```

Production validation:

```bash
npm run verify
```

Full Chromium release gate after installing Playwright's browser:

```bash
npx playwright install --with-deps chromium
npm run verify:release
```

The RSVP surface is intentionally non-delivering in this foundation checkpoint; it cannot show a false success state. Persistence and the transactional notification outbox are the next vertical-slice milestone.
